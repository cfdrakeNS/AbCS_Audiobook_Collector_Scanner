## Recommended Message Standard (for consistency)

Use one consistent, screen-reader-friendly format:

### Fallback
- `F: Title fallback from file used`
- `F: Title fallback from folder used`
- `F: Author fallback from folder used`

### Auto-correction
- `C: Auto-correct applied to Author`
- `C: Auto-correct applied to Title`
- `C: Auto-correct applied to Author, Title` (when both fields change)

**Notes:** 
- Auto-correction flags are only emitted for Title and Author changes. Genre, Series, and Narrator corrections are applied silently to avoid excessive flagging.
- If a field has a fallback flag (F:), the auto-correction flag (C:) is suppressed for that field to avoid duplicate flagging.
