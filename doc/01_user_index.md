# AbCS User Index

These guides describe major workflows in AbCS (Audio Book Collector Scanner) in plain language. They are written for users of screen readers such as JAWS or NVDA. Each guide explains what to do, what to listen for, and what to check.

## How to use these guides

- Press **F1** in any window for that window's keyboard shortcuts.
- Press **Alt+/** to re-read the current status message.
- Press **Escape** to cancel or close most dialogs (some ask for confirmation first).

Trial builds may expire after 30 days. If the app will not start, download a newer build.

## Suggested order for new users

If you are new to AbCS, this order builds on each step:

A default collection named **Audio Books** is created when the database is first set up. You can import into it right away; use the Collections guide when you want to rename it or add more collections.

1. **Import** — add books from audio folders (the main workflow). See [02 Import](02_import_process.md).
2. **Find and Filters** — browse and narrow the book list. See [03 Find and Filters](03_find_filters_process.md).
3. **Update and New Book** — fix metadata or add a manual entry. See [04 Update and New Book](04_update_new_book_process.md).
4. **Collections** — rename the default collection or add more collections to organize your library. See [05 Collections](05_collections_process.md).
5. **Web Metadata Fetch** — enrich a book with online details. See [06 Web Metadata Fetch](06_web_metadata_fetch_process.md).
6. **Duplicate Mode** — find and remove duplicate entries. See [07 Duplicate Mode](07_duplicate_mode_process.md).
7. **Backup and Restore** — confirm you can save and recover your data. See [08 Backup and Restore](08_backup_restore_process.md).

**Import Book List** is a separate import path; use it when you have a spreadsheet to import, or after folder import is working. See [10 Import Book List](10_import_book_list_process.md).
