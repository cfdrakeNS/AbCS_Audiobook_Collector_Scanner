# Want to read and playing filter — dropped

**Status:** Dropped from version 3 (September 2026)  
**Reason:** Separate **Want to read** and **In progress** filters already ship (Phases 20 and 21). A combined union filter is not needed.

---

## What this would have been

One View filter showing books that are Want to read **or** in progress (playing). Not implemented.

Use View → Want to read and View → In progress instead.
