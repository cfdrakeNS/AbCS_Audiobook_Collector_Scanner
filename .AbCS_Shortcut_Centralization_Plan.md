# Shortcut_Centralization_Plan**

1. **Overview**
   - Goal: Move all Alt+letter shortcut definitions and registrations to ShortcutManager (shortcuts.py).
   - Benefits: Accessibility, maintainability, easier testing, consistent F1 menus.

2. **Change Outline (by Window/Function)**

    **A. MainWindow**
    - Centralized (March 2026):
       - Alt+U (Update selected), Alt+D (Delete selected), Alt+L (Cancel selection) are registered via ShortcutManager.
       - Alt+B (book list focus) was removed; focus is managed programmatically to first title in table for accessibility.
    - Scope: All action shortcuts are managed by ShortcutManager. No accessibility exceptions required.

    **B. BookDetailsWindow**
    - Needs Centralizing:
       - Title (Alt+T)
       - Author (Alt+A)
       - Year (Alt+Y)
       - Files (Alt+F)
       - Series (Alt+I)
       - Genre (Alt+G)
       - Reader (Alt+R)
       - Collection (Alt+C)
       - Length (Alt+M)
       - Read date (Alt+E)
       - Size (Alt+Z)
       - Bitrate (Alt+B)
       - Path (Alt+H)
       - Comments (Alt+O)
       - New (Alt+N)
       - Save (Alt+S)
       - Delete (Alt+D)
       - Cancel (Alt+L)
    - Scope: Move all to ShortcutManager.

    **C. ImportWindow**
    - Centralized (March 2026):
       - All Alt+letter shortcuts except Alt+W (Browse) are registered via ShortcutManager.
       - Alt+W (Browse) remains local, handled in keyPressEvent for accessibility-first (JAWS/NVDA) users. This is a critical exception to centralization, per Copilot_JAWS_Working_Agreement.
       - Collection field (Alt+C)
       - Folder field (Alt+F)
       - Error filter (Alt+E)
       - Browse (Alt+W)
       - Import Selected (Alt+S)
       - Add Valid (Alt+V)
       - Focus import list table (Alt+B)
       - Export list to CSV (Alt+X)
    - Callback map must match widget names exactly (e.g., 'add_valid_button', 'export_button', 'import_selected_button', etc.)
    - All Alt+letter shortcuts in ShortcutManager must be registered in ImportWindow.
    - Focus actions for table and other widgets must be included.
    - Test each shortcut after centralization.
    - Local Only:
       - Status bar (Alt+/) shortcut remains a local QShortcut for reliability and screen reader support. Do NOT centralize Alt+/.
    - Scope: All field/action shortcuts are managed by ShortcutManager except Alt+/ (status bar), which is always local.

    **D. UpdateWindow**
    - Centralized:
       - Series (Alt+S)
       - Genre (Alt+G)
       - Collection (Alt+C)
       - Focus book list (Alt+B)
    - Local Only:
       - Status bar (Alt+/) shortcut remains a local QShortcut for reliability and screen reader support. We decided NOT to move Alt+/ to ShortcutManager; it stays local in each window where used.
    - Scope: All field/action shortcuts are managed by ShortcutManager except Alt+/, which is always local.

    **E. PreferencesWindow**
    - Centralized (March 2026):
       - Display section (Alt+D)
       - Path & Scope section (Alt+P)
       - Options section (Alt+O)
       - Fallback section (Alt+F)
       - Validation Rules section (Alt+R)
       - Auto-Correction section (Alt+A)
       - Save (Alt+S)
       - Cancel (Alt+L)
    - Local Only:
       - Status bar (Alt+/) shortcut remains local for screen reader support. Do NOT centralize Alt+/.
    - Scope: All above shortcuts are now managed by ShortcutManager except Alt+/ (status bar), which is always local. Registration bug fixed (ShortcutContext.PREFERENCES_WINDOW and shortcut handler).

    **F. Other Windows (Collection, Author, Genre, Series, etc.)**
    - Needs Centralizing:
       - Audit required for each window.
    - Scope: Move all to ShortcutManager.

    **G. ImportDetailWindow**
    - Needs Centralizing:
       - All Alt+letter shortcuts for import detail actions (edit, fix, keep/discard, navigation, error view, etc.)
    - Scope: Move all to ShortcutManager. Add Alt+/ as local for status bar read.

3. **Testing Checklist**
   - After each window/function change:
     - Test all Alt+letter shortcuts.
     - Verify F1 menu displays correct shortcuts.
     - Confirm screen reader and keyboard navigation.

4. **Documentation**
   - Update shortcut CSV and docs to reflect central mapping.
