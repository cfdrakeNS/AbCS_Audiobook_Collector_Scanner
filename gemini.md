# Gemini Code Assist Instructions

## User Preferences
- **Screen Reader:** I use the JAWS screen reader. 
- put your responses in the file gemini_chat_response for easier reading of chats 
- **Formatting:** Please ensure all responses are JAWS-friendly. 
- **Descriptions:** Provide a clear text summary of what code changes do before providing the code blocks.
- **Diffs:** When providing diffs, please explain which lines are being changed and why, so it is easier to follow with a screen reader.

## Project Context
- This is the AbCS (Audio Book Collector Scanner) project using Python and PySide6.
