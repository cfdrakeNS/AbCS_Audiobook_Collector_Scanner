# Web Enhancement Build 
 
## Files Included: 
- web_metadata.py - Main web metadata window 
- web_metadata_backup.py - Backup reference implementation 
 
## Features: 
- Real web data fetching from Google Books API 
- Field validation and matching 
- Popup for field changes 
- Auto-save in book details 
- Accessibility support (JAWS/NVDA) 
 
## Installation: 
1. Backup your current files 
2. Copy files to src\ui\ directory 
3. Install requests: pip install requests 
4. Restart application
