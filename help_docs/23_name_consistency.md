# Name Consistency Check

## What this is

Name Consistency Check finds authors and genres whose names are spelled almost the same (for example `John Connelly` / `John Connely`) and lets you merge each group into one canonical name after you confirm.

This is **not** Duplicate Mode. Duplicates are the same book stored twice. Consistency is the same person or genre spelled differently.

## When to use it

- After imports from different sources left near-duplicate author or genre spellings.
- When Find or filters show the same author under two spellings.

## Before you start

- Import is blocked while the review dialog is open.
- Merges are never automatic — you confirm each group.

## Steps

1. Open **Manage → Name Consistency Check...** (**Alt+M**, then **N**).
2. Review each group: the list shows spellings and book counts; the suggested name is marked.
3. Choose **Merge into suggested**, **Skip group**, or **Close**.
4. When finished, the main window refreshes and the status bar reports how many groups were merged or skipped.

## Mouse, shortcuts, and accessibility

- Focus starts on **Merge into suggested** when groups exist, or on the summary text when none do.
- Press **Alt+/** to re-read the status bar on the main window after the dialog closes.
- Press **Escape** / **Close** to exit without further merges.
