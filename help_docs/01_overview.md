# AbCS Help Overview

These guides describe major workflows in AbCS (Audio Book Collector Scanner) in plain language. They are written for users of screen readers such as JAWS or NVDA. Each guide explains what to do, what to listen for, and what to check.

## How to use help

- Open **Help** on the main menu and choose a topic, or press **Shift+F1** in any window for help about that window.
- In the help window, use the **Help Topic** combo (**Alt+H**) to switch topics.
- Press **F1** in any window for that window's keyboard shortcuts.
- Press **Alt+/** to re-read the current status message.
- Press **Escape** to cancel or close most dialogs (some ask for confirmation first).

## Suggested order for new users

A default collection named **Audio Books** is created when the database is first set up. You can import into it right away; use the Collections guide when you want to rename it or add more collections.

1. **Import** — add books from audio folders. See [02 Import](02_import_process.md).
2. **Find and Filters** — browse and narrow the book list. See [03 Find and Filters](03_find_filters_process.md).
3. **Book Details** — fix metadata or add a manual entry. See [04 Book Details](04_book_details_process.md).
4. **Collections** — organize your library. See [06 Collections](06_collections_process.md).
5. **Web Metadata Fetch** — enrich a book with online details. See [07 Web Metadata Fetch](07_web_metadata_process.md).
6. **Duplicate Mode** — find and remove duplicate entries. See [08 Duplicate Mode](08_duplicate_mode_process.md).
7. **Backup and Restore** — confirm you can save and recover your data. See [09 Backup and Restore](09_backup_restore_process.md).

**Import Book List** is a separate import path; use it when you have a spreadsheet to import. See [11 Import Book List](11_import_book_list_process.md).
