# Glossary

## What this is

This guide explains the words AbCS uses in its windows, messages, and help. Each entry links to the guide that covers it.

## Library words

**Collection**
A named group of books inside AbCS, such as Audiobooks or a portable drive. Every book belongs to one collection. See [Collections](06_collections.md).

**Active collection**
A collection that appears in the import collection lists. At least one collection is always active. See [Collections](06_collections.md).

**Collection folder**
The top folder on disk where a collection's audiobook files are stored. Import, Listen, and Check Book Locations use it. See [Collections](06_collections.md).

**Default import directory**
The folder the Import window starts with, set in Preferences. See [Preferences](10_preferences.md).

**Path**
The folder or file where a book's audio is stored on disk. It shows in Book Details. See [Check Book Locations](24_check_book_locations.md).

**Series number**
The position of a book in its series, such as 3 or 6.5. The main table shows it after the title, for example " - 03". See [Book Details](04_book_details.md).

**Read date**
The day you marked a book as read. Reading History uses it. See [Reading History](13_reading_history.md).

**Want to read**
A mark for books you plan to listen to. The Want to read filter shows them. See [Find and Filters (Main Window)](03_find_filters.md).

**Listening position**
The place in a book where you stopped listening. Listen resumes from it. See [Listen to a book](26_listen_to_a_book.md).

**Listen progress**
The percent of a book you have listened to, shown in Book Details. See [Listen to a book](26_listen_to_a_book.md).

## Import words

**Import scenario**
The Preferences setting that tells Import how your folders are organized, such as Mass Standard Import. See [Import preferences](18_import_preferences.md).

**Tag**
Information stored inside an audio file, such as album, artist, or comment. Import reads tags to fill book fields. See [Import explained](19_import_explained.md).

**Held for review**
A book that Import found but did not add yet, because it needs your attention. It waits in the Import review table. See [Import (Folder Scan)](02_import.md).

**Fallback (F:)**
A book field filled from a folder or file name because its tag was missing. Books with a fallback are held for review. See [Import preferences](18_import_preferences.md).

**Auto-correct (C:)**
A text cleanup Import made, such as proper case or removing extra spaces. A correction holds the book for review unless Skip review is checked. See [Import preferences](18_import_preferences.md).

**Skip review**
The Preferences checkbox under each auto-correct option. When checked, that correction alone lets a book be added automatically. See [Import preferences](18_import_preferences.md).

**Validation rule**
A check Import runs on each book, such as a title that is too short. Each rule is set to None, Warning, or Error. See [Default preferences](17_default_preferences.md).

**Duplicate**
A book that matches one already in your library, by the fields set in Duplicate match. See [Duplicate Mode](08_duplicate_mode.md).

**Fuzzy duplicate**
A near-match on title and author, measured as a percent. See [Default preferences](17_default_preferences.md).

## Window words

**Status bar**
The line at the bottom of most windows that reports what just happened. Press **Alt+/** to hear it again. See [AbCS Help Overview](01_overview.md).

**Filter summary**
The line above the main book table that lists the active collection, filters, and sort. See [Find and Filters (Main Window)](03_find_filters.md).

**Selection**
The books you selected with **Shift+Down Arrow**, **Shift+Up Arrow**, or the mouse. Update, Delete, and batch Web fetch work on the selection. See [Find and Filters (Main Window)](03_find_filters.md).

**Focused book**
The book under the keyboard cursor in the main table. Listen and a single Fetch Web Info use it. See [Find and Filters (Main Window)](03_find_filters.md).

**Duplicate mode**
A main window mode that shows only duplicate books, so you can delete or export them. See [Duplicate Mode](08_duplicate_mode.md).

**Batch fetch**
Fetch Web Info for two or more selected books at once. See [Web Metadata Fetch](07_web_metadata.md).
