# Name List Process

## What this is

The Name List window lets you view and manage author, series and genres, or other name lists used by AbCS. You can search names, edit entries, and (in collection mode) mark names active or inactive.

## When to use it

- Open from the main window by activating an **Author**, **Series**, or **Genre** cell and pressing **Enter**.
- Use **Manage → Collections** when working with collection-specific name lists.

## Before you start

- Changes may affect how books are grouped or filtered in the main list.
- Save edits before closing if the **Save** button is available.

## Steps

1. Open the name list from the main book table (focus a name cell and press **Enter**), or from a collection workflow.
2. Use **Alt+L** to move focus to the list.
3. Use **Alt+M** to edit the name field, or **Alt+E** to edit the selected row.
4. In collection mode, use **Alt+A** for the active checkbox.
5. Use **Alt+F** (non-collection mode) to clear find and start a new search.
6. Press **Escape** to cancel an edit or close the window.

## Keyboard shortcuts

- **Shift+F1** — Open this help document.
- **F1** — Show keyboard shortcuts for this window.
- **Alt+/** — Re-read the status bar.
