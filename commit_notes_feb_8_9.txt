Commit Notes - February 8-9, 2026
==================================

BOOK DETAILS WINDOW CHANGES
---------------------------

**Save Button & Shortcut:**
- Changed Save shortcut from Alt+V to Alt+S (more intuitive)
- Button text now "&Save" instead of "Sa&ve"
- Save no longer closes the window - stays on current book
- After save, dirty flag cleared and original combo values updated

**Combo Box Change Detection (Author, Series, Genre):**
- On focusOut, if combo value is new (not in database), shows Yes/No dialog:
  "'{value}' is a new {field}. Create this new {field}?"
- If No: reverts combo to original value
- If Yes: allows the new value (will be created on save)
- Removed redundant confirmation dialogs from on_save (already handled on focusOut)

**Navigation Protection:**
- Page Up/Down blocked with beep when there are unsaved changes
- Prevents accidentally losing edits when navigating between books

**Close/Escape Dialog (Unsaved Changes):**
- Three-button dialog: Yes / No / Cancel
- Yes = Save and stay on the book
- No = Focus the first field that had changes (don't close)
- Cancel = Revert all fields to original values (don't close)
- Added _revert_changes() method to reload book data or clear form

**Delete Behavior:**
- Delete no longer closes the window
- After delete, navigates to next book in list
- If deleted book was last in list, moves to previous book
- Only closes if no books remain

**UI Styling:**
- All form labels now bold (font-weight: bold)
- Button heights compact - match scaled input field heights
- Uses scaled_height from current zoom level

**Combo Box Arrow Key Protection:**
- Plain Up/Down arrow keys blocked on combo boxes (beeps)
- Requires Alt+Up/Down to navigate combo items
- Prevents silent value changes that JAWS doesn't announce

**Dirty Tracking Enhancement:**
- Now tracks which widget first became dirty (_first_dirty_widget)
- Used to focus that field when user clicks No on close dialog


MAIN WINDOW CHANGES
-------------------

**Button Styling:**
- Added compact button styling (Update, Delete, Cancel)
- Buttons now have min-height/max-height matching scaled_height
- Initial styling applied at startup via on_scale_changed(current_scale)
