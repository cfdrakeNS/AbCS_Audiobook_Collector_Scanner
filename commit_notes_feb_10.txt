## Update Window Implementation

Created new bulk update dialog (src/ui/update_window.py) for mass updating Series, Genre, and Collection on selected books.

### Features:
- Three editable combo boxes (Series, Genre, Collection) in header
- Table displaying selected books with Year, Series, Genre, Collection columns
- Immediate database updates when combo selection changes
- "None" option to clear fields from selected books
- New entry support: type new Series/Genre, confirmation popup, adds to database
- F1 keyboard shortcuts help dialog

### Accessibility:
- Full keyboard navigation with Alt+letter shortcuts
- Screen reader announcements for status bar messages (JAWS/NVDA)
- Uses QAccessible focus trick pattern from main_window
- Scaled fonts via UIScaler
- High contrast theme support

### Technical Details:
- UIScaler uses `current_scale` property (percentage-based)
- Event filters block plain Up/Down arrows on combos (Escape still works)
- FocusOut detection triggers new entry confirmation
- Column resize modes: Year (ResizeToContents), others (Interactive)
- Window size: 1200x500 minimum
- Enter key in combos confirms new entries, Tab navigates between fields

### Bug Fixes Applied:
- Fixed UIScaler.scale() → current_scale property
- Fixed column widths not applying (changed from Fixed to Interactive mode)
- Simplified Enter key handling (removed complex navigation logic)
- Fixed focus restoration after status bar announcements
