Test Plan - Main Window & Book Details
=======================================
Focus: Recent functional changes (Feb 8-9, 2026)


BOOK DETAILS WINDOW TESTS
=========================

1. SAVE SHORTCUT (Alt+S)
------------------------
[ ] Alt+S triggers save when Save button visible
[ ] Button shows "&Save" with S underlined
[ ] Accessible description says "Alt+S"
[ ] F1 shortcuts dialog shows "Alt+S - Save"

2. SAVE BEHAVIOR (Stay Open)
----------------------------
[ ] Edit a field, press Alt+S or click Save
[ ] "Book updated successfully!" message appears
[ ] Window stays open (does NOT close)
[ ] Save button hides after save (no longer dirty)
[ ] Window title still shows book name
[ ] Edit another field - Save button reappears

3. COMBO CHANGE DETECTION (FocusOut)
------------------------------------
Test Author combo:
[ ] Tab to Author, type a new author name not in database
[ ] Tab away (or click elsewhere) - dialog appears:
    "'{name}' is a new Author. Create this new Author?"
[ ] Click No - author reverts to original value
[ ] Click Yes - new author name stays, Save button appears

Test Series combo:
[ ] Same test - type new series, tab away
[ ] No reverts, Yes keeps value

Test Genre combo:
[ ] Same test - type new genre, tab away
[ ] No reverts, Yes keeps value

[ ] Existing values: select an existing item from dropdown, tab away - no dialog

4. PAGE UP/DOWN PROTECTION
--------------------------
[ ] Make a change to any field (dirty = true)
[ ] Press Page Down - hear beep, nothing happens
[ ] Press Page Up - hear beep, nothing happens
[ ] Save the change (dirty = false)
[ ] Press Page Down - navigates to next book
[ ] Press Page Up - navigates to previous book

5. CLOSE DIALOG (Escape with Changes)
-------------------------------------
[ ] Make a change to a field
[ ] Press Escape - dialog appears with three buttons: Yes, No, Cancel

Test Yes button:
[ ] Click Yes - book saves, window stays open, Save button hidden

Test No button:
[ ] Make a change, press Escape, click No
[ ] Cursor moves to the field that was changed
[ ] Window stays open, change still visible

Test Cancel button:
[ ] Make a change, press Escape, click Cancel
[ ] All fields revert to original values
[ ] Window stays open, Save button hidden (no longer dirty)

[ ] No changes - press Escape - window closes immediately (no dialog)

6. DELETE NAVIGATION
--------------------
Setup: Have at least 3 books in list

[ ] Open book #2 of 3
[ ] Click Delete, confirm Yes
[ ] "Book deleted successfully!" message
[ ] Window shows book #3 (moved to next)
[ ] Window title updated to new book's title

[ ] Now on last book, click Delete, confirm Yes
[ ] Window shows previous book (moved back)

[ ] Delete until only 1 book remains
[ ] Delete that book, confirm Yes
[ ] "Book deleted. No more books." message
[ ] Window closes

7. COMBO BOX ARROW KEY PROTECTION
---------------------------------
[ ] Tab to Author combo
[ ] Press plain Down arrow - hear beep, value doesn't change
[ ] Press plain Up arrow - hear beep, value doesn't change
[ ] Press Alt+Down - dropdown opens, JAWS announces items
[ ] Arrow down in dropdown - JAWS announces each item
[ ] Press Enter or Escape to close dropdown

[ ] Same test for Series combo
[ ] Same test for Genre combo

8. LABEL STYLING
----------------
[ ] All form labels appear bold (Title:, Author:, Year:, etc.)
[ ] Labels visually distinct from field values

9. BUTTON SIZING
----------------
[ ] Buttons (New, Save, Delete, Close) have compact height
[ ] Buttons not excessively tall
[ ] All buttons same height as input fields
