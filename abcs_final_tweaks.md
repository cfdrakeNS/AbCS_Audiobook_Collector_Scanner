## Centralizing Icon Usage

**Should the icon be centralized and code refer to it?**

Yes. For maintainability and consistency, define the icon path (e.g., `data/graphics/abCS_icon.ico`) in a single location (such as a constant or utility function/class). All windows and popups should reference this, so any icon change is global and consistent. This also helps with accessibility and branding.

**Suggested approach:**
- Create a utility function or constant for the app icon (e.g., `get_app_icon()` in a shared module).
- Use this for all `setWindowIcon` and popup icon settings.
- Update all popups to call `setWindowIcon(get_app_icon())` after construction.
